# SUT Findback

🌐 [English](README.md) | [ภาษาไทย](README.th.md)

**แอปพลิเคชันตามหาของหายภายในมหาวิทยาลัยเทคโนโลยีสุรนารี**

SUT Findback เป็นศูนย์กลางให้นักศึกษาและบุคลากรแจ้งของหาย ประกาศพบสิ่งของ และติดต่อเพื่อรับคืน โดยรวบรวมโพสต์ที่ค้นหาได้ ข้อมูลสถานที่ และการสนทนาแบบเรียลไทม์ไว้ในระบบเดียว ช่วยลดปัญหาประกาศที่กระจัดกระจายตามกลุ่มบนสื่อสังคมออนไลน์

**รายวิชา:** Project in Scripting Language Application Development

**ระยะเวลาพัฒนาโครงงาน:** มีนาคม–พฤษภาคม 2569

**ประเภทโครงงาน:** โครงงานรายวิชาที่พัฒนาร่วมกันเป็นทีม

## ส่วนที่รับผิดชอบ

รับผิดชอบการพัฒนาแอปพลิเคชัน Mobile ทั้งหมด ครอบคลุมหน้าจอ การนำทาง ขั้นตอนการใช้งาน และการเชื่อมต่อกับ Firebase, Google Maps และ Cloudinary โดยมีสมาชิกในทีมร่วมพัฒนาส่วนอื่นของโครงงาน รวมถึงเว็บสำหรับผู้ดูแลระบบ

## ฟีเจอร์

### แอปพลิเคชัน Mobile

- **บัญชีและโปรไฟล์:** สมัครสมาชิก เข้าสู่ระบบด้วยอีเมลหรือชื่อผู้ใช้ รีเซ็ตหรือเปลี่ยนรหัสผ่าน และแก้ไขข้อมูลกับรูปโปรไฟล์
- **โพสต์ของหายและพบของ:** สร้าง แก้ไข และลบโพสต์ พร้อมระบุหมวดหมู่ วันที่ รายละเอียด รูปภาพ และจุดรับคืน รองรับการถ่ายภาพและเลือกรูปจากคลังภาพ
- **ระบุสถานที่:** ใช้ GPS และ Google Maps ระบุตำแหน่งที่ทำของหายหรือพบสิ่งของ
- **ค้นหาและกรองข้อมูล:** ค้นหาด้วยคำสำคัญ และกรองตามประเภทโพสต์ หมวดหมู่ วันที่ สถานที่ และสถานะ
- **แชทแบบเรียลไทม์:** ส่งข้อความ รูปภาพ และการ์ดโพสต์ เพื่อประสานงานและนัดรับคืนสิ่งของ
- **การแจ้งเตือน:** ติดตามข้อความใหม่ การกดรับของ การเปลี่ยนสถานะโพสต์ และผลการตรวจสอบรายงานแบบเรียลไทม์
- **รายการส่วนตัว:** บันทึกโพสต์และดูโพสต์ของฉัน โพสต์ที่บันทึกไว้ และรายการรับของของฉัน
- **การรับคืนและรายงานโพสต์:** อัปเดตสถานะการรับคืนสิ่งของ และรายงานโพสต์ที่ไม่เหมาะสม

### เว็บสำหรับผู้ดูแลระบบ

- Dashboard แสดงสถิติโพสต์ ผู้ใช้ รายงาน และรายการที่ปิดเคสแล้ว
- ตรวจสอบโพสต์และจัดการสถานะ
- ตรวจสอบรายงานและจัดการบัญชีผู้ใช้
- สนทนาเพื่อให้ความช่วยเหลือผู้ใช้

## โครงสร้างโปรเจกต์

```text
app/                 หน้าจอ Mobile และ layout ของ Expo Router
components/          คอมโพเนนต์ที่ใช้ร่วมกันและ context ข้อมูลผู้ใช้
constants/           การตั้งค่า Firebase ค่าที่ใช้ร่วมกัน และบริการต่าง ๆ
hooks/               Hook สำหรับการแจ้งเตือน ธีม และการทำงานร่วมกัน
assets/              รูปภาพ ไอคอน และไฟล์ประกอบหน้าจอ
admin/               เว็บสำหรับผู้ดูแลระบบ แยกจากแอป Mobile
screens/             โค้ดหน้าจอเพิ่มเติม
scripts/             สคริปต์จัดการโปรเจกต์
app.json             การตั้งค่า Expo
firebase.json        การตั้งค่า Firebase Hosting และ Functions
```

## การติดตั้งและเริ่มใช้งาน

### สิ่งที่ต้องเตรียม

- Node.js รุ่น 24 ตั้งแต่ 24.3 ขึ้นไป พร้อม npm
- Expo Go ที่รองรับ SDK 58 หรือ development build ที่เข้ากันได้
- สิทธิ์เข้าถึงบริการ Firebase, Google Maps และ Cloudinary ที่ตั้งค่าไว้

### 1. ดาวน์โหลดและติดตั้งแพ็กเกจ

```bash
git clone https://github.com/ichiniran/sut-findback.git
cd sut-findback
npm install
```

### 2. ตั้งค่าบริการ

ปัจจุบันค่าบริการต่าง ๆ กำหนดอยู่ในไฟล์โค้ด และยังไม่ได้เชื่อมต่อกับตัวแปรสภาพแวดล้อม หากต้องการใช้บริการของตนเอง ให้แก้ไขไฟล์ต่อไปนี้

| บริการ | ตำแหน่งที่ตั้งค่า |
| --- | --- |
| Firebase | `constants/firebase.ts`, `admin/src/firebase.ts` |
| Google Maps | `app/post-form.tsx` |
| ชื่อ cloud และ upload preset ของ Cloudinary | `app/post-form.tsx`, `app/edit-profile.tsx`, `app/chat/ChatDetail.tsx`, `admin/src/pages/AdminChatInbox.tsx` |
| บัญชีผู้ดูแลสำหรับติดต่อช่วยเหลือ | `constants/admin.ts`, `admin/src/constants/admin.ts` |
| โปรเจกต์ Firebase สำหรับ deploy | `.firebaserc` |

เปิดใช้งานการเข้าสู่ระบบด้วยอีเมลและรหัสผ่านใน Firebase Authentication พร้อมเตรียมฐานข้อมูล Firestore และกฎการเข้าถึงข้อมูลให้เหมาะกับโปรเจกต์ เว็บผู้ดูแลระบบตรวจสิทธิ์จากเอกสาร `admins/{uid}` ของบัญชีที่เข้าสู่ระบบ ส่วนการค้นหาข้อมูลบางรายการอาจต้องสร้าง Firestore index เพิ่ม โดยทำตามลิงก์ที่ Firebase แสดงระหว่างพัฒนา

### 3. เปิดแอป Mobile

```bash
npx expo start --go --clear
```

เชื่อมต่อมือถือกับคอมพิวเตอร์ผ่าน Wi-Fi เดียวกัน แล้วสแกน QR code หากใช้ iPhone เครื่องจริง ต้องเข้าสู่ระบบ Expo Go และ Expo CLI ด้วยบัญชี Expo เดียวกัน

```bash
npx expo login
npx expo whoami
```

หากเข้าสู่ระบบผ่านเบราว์เซอร์ไม่สำเร็จ ให้ใช้ `npx expo login --no-browser` หากเชื่อมต่อผ่านเครือข่ายในพื้นที่ไม่ได้ ให้ใช้ `npx expo start --go --tunnel --clear` แทน

### 4. เปิดเว็บผู้ดูแลระบบ

เว็บผู้ดูแลระบบมีแพ็กเกจแยกต่างหาก หลังติดตั้งแพ็กเกจที่โฟลเดอร์หลักแล้ว ให้รันคำสั่งต่อไปนี้

```bash
cd admin
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal แล้วเข้าสู่ระบบด้วยบัญชีที่ได้รับสิทธิ์ผู้ดูแล

### สำหรับ Windows PowerShell

หาก PowerShell บล็อก `npm.ps1` หรือ `npx.ps1` ให้เปลี่ยนจาก `npm` และ `npx` เป็น `npm.cmd` และ `npx.cmd` ในคำสั่งข้างต้น

## การ Build และเผยแพร่เว็บ

เปิดแอป Expo เวอร์ชันเว็บในเครื่อง

```bash
npm run web
```

สร้างไฟล์เว็บแบบ static

```bash
npm run build:web
```

ผลลัพธ์จะอยู่ในโฟลเดอร์ `dist/` โดย Firebase Hosting ถูกตั้งค่าให้เผยแพร่ไฟล์จากโฟลเดอร์นี้ และ build เว็บอัตโนมัติก่อน deploy

```bash
npx -y firebase-tools@latest deploy --only hosting
```

โปรเจกต์ Firebase เริ่มต้นใน repository คือ `sut-find-back` หากต้องการ deploy ไปยังโปรเจกต์อื่น ให้แก้ไข `.firebaserc` คำสั่งนี้เผยแพร่เว็บจาก Expo ส่วนเว็บผู้ดูแลระบบมีขั้นตอน build ด้วย Vite แยกกัน ใช้ `--only hosting` เนื่องจากมีการตั้งค่า Functions อยู่ใน repository แต่ไม่มีโฟลเดอร์โค้ด `functions/` ที่อ้างถึง

## การตรวจสอบและข้อจำกัดปัจจุบัน

```bash
npx tsc --noEmit
npx expo install --check
npx expo-doctor
```

- การตรวจ TypeScript ที่โฟลเดอร์หลักไม่รวมโปรเจกต์ `admin/` หลังติดตั้งแพ็กเกจของ Admin แล้ว สามารถตรวจการ build แยกด้วย `npm --prefix admin run build`
- การยืนยันเบอร์โทรศัพท์เดิมใช้แพ็กเกจ `expo-firebase-recaptcha` ที่เลิกรองรับแล้ว โดย Expo Doctor จะรายงานแพ็กเกจนี้และ `expo-constants` รุ่นเก่าที่ติดตั้งมาด้วย ระบบ OTP ยังต้องปรับไปใช้แนวทางใหม่และทดสอบบนอุปกรณ์จริงแยกต่างหาก
- การแจ้งเตือนบนเบราว์เซอร์มีข้อจำกัดต่างจากแอป Mobile ควรทดสอบการแจ้งเตือน กล้อง แผนที่ และตำแหน่งบนอุปกรณ์ที่ต้องการใช้งาน
- โปรเจกต์นี้เป็นโครงงานรายวิชาที่ทำร่วมกันเป็นทีม การอัปเกรด SDK 58 และปรับการเผยแพร่เกิดขึ้นภายหลังช่วงพัฒนาเดิมในเดือนมีนาคม–พฤษภาคม 2569
